Getting Started with Cretes

Cretes uses a provisional Phase 4 syntax frontend implemented in Rust 1.85.1 with zero third-party Rust dependencies. The toolchain compiles directly using standard Cargo tools.

Pinned Toolchain
The Cretes compiler frontend targets Rust 1.85.1 (specified in rust-toolchain.toml). Ensure you have cargo and rustc installed.

Building the Frontend

Clone the core repository and compile the binaries:

1git clone https://github.com/Cretes-lang/cretes.git
2cd cretes
3cargo build --locked
4cargo test --locked

Your First Cretes Program

Create a file named main.cretes with the following content:

1import std::io;
2
3fn main() -> Result[i32, io::Error] {
4 io::println("Hello, Cretes!")?;
5 return Result::Ok(0);
6}

Parse and inspect the program using the front-end utility:

1cargo run --bin cretes-front -- parse main.cretes

Variables and Mutability

In Cretes, variables are immutable by default when declared with let. Mutable variables must explicitly use the var keyword.

1// Immutable binding
2let count: i64 = 42;
3
4// Mutable binding
5var accumulator: f64 = 0.0;
6accumulator = accumulator + 1.5;

Memory Borrowing & Provenance

Cretes enforces safe compile-time borrowing. References are created using & and mutable references using &mut. To eliminate dangling pointers without a tracing garbage collector, Cretes introduces the explicit from provenance syntax for returning borrowed references:

1fn first(values: &Seq[i64]) -> &i64 from values {
2 return &(*values)[0];
3}
4
5fn increment(value: &mut i64) -> () {
6 *value = *value + 1;
7}
Zero-cost Lifetime Tracking
The from values clause informs the compiler that the returned pointer's validity is bounded by the lifetime of the input parameter values.

Result Error Handling

Cretes eliminates unhandled null pointers and unmonitored exceptions. Fallible functions return Result[T, E], which is either Result::Ok(val) or Result::Err(err). The ? operator unwraps the successful value or immediately returns the error from the caller function.

1import std::fs;
2
3fn process_config(path: &String) -> Result[Bytes, fs::Error] {
4 let contents = fs::read_bytes(path)?;
5 return Result::Ok(contents);
6}

Standard Library Overview

Cretes ships with an audited, minimal standard library focused on systems programming, cyber defense, and automation.

Module Primary APIs Target Domain
std::io print, println, read_line Terminal I/O and formatted streams
std::bytes len, slice, from_slice Zero-copy memory slices & network buffers
std::fs read_bytes, write_bytes, exists Deterministic filesystem automation
std::net TcpStream, UdpSocket High-throughput networking and cyber defense
