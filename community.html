RFC Process

How Language Features Evolve

Every syntactic addition, type system extension, and standard library API undergoes strict phase gates.

STAGE 1
Exploration Issue
Problem statement filed in GitHub Discussions or issues demonstrating concrete requirements.
STAGE 2
Draft RFC Proposal
Formal grammar changes, grammar safety checks, and edge case specifications drafted in Cretes-lang/rfcs.
STAGE 3 (CURRENT)
Phase Candidate
Implementation of the syntax frontend in cretes-front with comprehensive test coverage and AST validation.
STAGE 4
Accepted Standard
Governance review signoff, merging into canonical language specification, and toolchain release.
